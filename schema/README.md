# Release Schema

The evaluated extraction used the fixed JSON output template embedded in `prompts/FROZEN_EXTRACTION_PROMPTS_v1.0.md`. The same structure is provided in `extraction_output_schema.json` as a documented release schema for validation and reuse.

The release schema is a machine-readable transcription of the frozen output template. It is supplied for reader convenience and is identified separately from the historical schema checksum recorded during experiment launch.

The 11 fields used for the headline core-field and complete-row metrics are listed in `core_fields.json`.
