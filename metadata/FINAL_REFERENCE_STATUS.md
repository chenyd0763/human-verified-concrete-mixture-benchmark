# Final Reference Status

## Released reference

The public workbook `S2_human_verified_concrete_mixture_benchmark_v1.2.xlsx` is the final consensus reference used for the results reported in the manuscript.

The reference was established through the following process:

1. A primary annotator reconstructed all eligible mixture and strength records from the 18 blind-test articles.
2. A second concrete researcher verified every critical numerical field against the original full text.
3. Disagreements were resolved by consensus through direct source reinspection.
4. The consensus records were locked before the final relabelled configuration scores were reported.

The public benchmark is therefore a human-verified consensus dataset. Provisional pilot annotations and internal reference-generation artifacts are not part of this release and were not used as the final reference for the published metrics.

## Agreement reporting

The second stage was conducted as complete source verification and consensus adjudication. Pre-adjudication ratings were not retained as a separate reliability dataset, so a pre-adjudication agreement coefficient is not reported.

## Source text

The release provides bibliographic identifiers and evidence locations. Publisher text and article files are excluded from the public package.
